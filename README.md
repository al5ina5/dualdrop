# Dualdrop

A LÖVE 2D puzzle game with local, LAN, and online multiplayer.

## Run

```bash
love .
```

Requires [LÖVE](https://love2d.org/) 11.5.

## Deploy (ES-DE)

```bash
npm run deploy:machines   # kiosk + aio
npm run deploy:kiosk
npm run deploy:aio
```

More detail in [docs/QUICK_START.md](docs/QUICK_START.md).
